## 📚 Getenberg API

A Django backend to fetch books from Project Gutenberg with filters, pagination, and download links.

### 🔧 Features
- Filter by language, author, title, MIME type
- Sort by download count
- Pagination (25 books per page)
- Deployed with Render + PostgreSQL

### 🚀 Live API:
https://ebook-57yx.onrender.com

### 🧪 Example Request
http://127.0.0.1:8000/api/books?page=2

### 🛠️ Tech Stack
- Django
- PostgreSQL
- Render
